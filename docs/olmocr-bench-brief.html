评估方法：怎么判

  1. 每条测试只判对或错。例如「这句话必须出现」「A 段必须在 B 段之前」「这个单元格的右边必须是那个值」。
  2. 两家做同一批页、同一批测试，一条一条配对比较。
  3. 只看两家结论不一致的那部分：「只有 Infinity 对」几条、「只有 Azure 对」几条，再用 McNemar 检验判断差异是否显著（p < 0.05）。两家都对或都错的条目不影响结论。
  4. 不合成总分：按子集分别给结果。p ≥ 0.05 写「未观察到显著差异」，不写「持平」。

公平性：已知的偏差都摆出来

事项处理
厂商主场：厂商自己在这个基准上报过分（全量 87.6%），不能排除训练时见过这批数据如实写明，对 Infinity 有利；我们跑的是抽样子集，分数不与 87.6% 比较
输入不同：Azure 收到 PDF 原件，Infinity 收到 300 DPI 图片（厂商 SDK 的做法）两家都按各自产品的标准用法调用
页眉页脚：Azure 把页眉页脚写成 HTML 注释，判分代码仍当作「出现在正文」，判 Azure 错这一行不作比较
公式类：公司网络装不上渲染公式所需的组件，Azure 侧没法判分两边都去掉公式类，604 条剩 499 条
调用失败：Infinity 有 1 页陷入复读、输出被截断；Azure 120 页全部成功两种算法都算了：失败页算错，或两边都去掉这一页。结论相同

这一层说明了什么

  • 能说明：在中立的公开题目上，Infinity 的基础解析能力达到 Azure 的水平，可以进入下一步评测；表格是需要重点盯的风险。
  • 不能说明：这个基准里没有财报。能否在金融公司场景替代，要看自建金融文档集的分文档类型结果。

Infinity-Parser2 vs Azure DI: Public Benchmark Comparison

On the same pages, scored by the same code, we observed no significant overall difference. Azure is clearly better on tables; Infinity's advantage shows up on handwritten historical letters, which have little to do with our use case.

Results

Infinity-Parser2Azure DIPass rate, 0–100%

Why tables differ so much: on 14 of 40 pages Infinity did not recognise the table as a table. The whole table came out as plain text, with rows and columns lost and no error raised. When it did recognise a table, 91% of its cells were correct. This "flattened table" failure is the highest risk for financial statements.

Test set: what we tested on

olmOCR-Bench: a public PDF parsing benchmark released by AllenAI (ODC-BY licence), 1,403 pages and 7,019 tests. Why this benchmark:

  • Third-party questions: neither we nor the vendor wrote the tests or the scoring code
  • Official scorer used as-is: pinned to commit ab294c6a, not a single line changed
  • Reproducible: fixed random seed for sampling; every raw output is kept, so any number can be recomputed

We sampled 120 pages / 499 tests, weighted towards financial-document relevance (formula tests excluded):

Method: how we scored

  1. Every test is pass or fail. For example: "this sentence must appear", "paragraph A must come before B", "the cell to the right of X must be Y".
  2. Both systems run the same pages and the same tests, compared test by test.
  3. Only disagreements count: how many tests only Infinity passed and how many only Azure passed. A McNemar test decides whether the difference is significant (p < 0.05). Tests both pass or both fail do not affect the result.
  4. No composite score: results are reported per subset. When p ≥ 0.05 we write "no significant difference observed", never "equal".

What this layer tells us

  • It shows: on neutral public tests, Infinity's basic parsing is at Azure's level and can move to the next stage; tables are the risk to watch.
  • It does not show: this benchmark has no financial statements. Replacement in the financial company's setting depends on per-document-type results from the in-house financial document set.
